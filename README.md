# Turtle Game

Exercice Python de dessin géométrique avec le module standard `turtle`.

## Objectif pédagogique

Le projet permet de travailler :

- `import turtle` ;
- la création d’une tortue graphique ;
- les fonctions ;
- les boucles `for` ;
- les déplacements avec `forward()` ;
- les rotations avec `left()` et `right()` ;
- la composition de formes réutilisables.

## Fonctionnement

Le fichier définit trois fonctions : `escalier()`, `carre()` et `carres()`. Dans l’état actuel, le script appelle `carres(10, 10)` et dessine dix carrés de taille croissante.

## Remarque pédagogique

Malgré le nom du dépôt, le code actuel n’implémente pas de logique de jeu, de score ou d’interaction utilisateur. Il s’agit principalement d’un exercice de dessin algorithmique avec `turtle`.

## Fichier principal

`main.py`

## Exécution

```bash
python main.py
```

L’exécution nécessite un environnement graphique compatible avec `turtle`.
